# **App Name**: eMenu QR Mobile

## Core Features:

- QR Table Recognition: Automatically detects the customer's table number from the scanned QR code for personalized service.
- Interactive Menu Browser: High-fidelity digital menu showing high-resolution images, detailed descriptions, and prices of available dishes.
- Multi-language Interface: Localized experience allowing users to switch languages instantly from the interface header.
- AI Taste Advisor tool: An AI-powered recommendation tool that suggests dishes and wine pairings based on current favorites or dietary restrictions.
- Direct Bill Payment: Integration with payment gateways to allow users to settle their bill directly from the mobile app.

## Style Guidelines:

- Primary color: A vibrant Teal (#12B4A3) used for main action buttons and the branding identity, evoking a fresh and modern dining feel.
- Typography color: Dark Navy (#1E2B4D) for high-contrast headlines and UI labels to ensure professional readability.
- Background: A sophisticated Light Sky Grey (#F0F4F8) that makes the clean white content cards pop off the screen.
- Headline and body font: 'Inter' (sans-serif) for a modern, machined, and neutral aesthetic as requested. Note: currently only Google Fonts are supported.
- Simplified vector-based icons for language selection, location tagging, and category navigation to mirror the provided screenshot's minimalist look.
- A vertical stack starting with an immersive food-focused hero image, transitioning into a floating white card container with large rounded corners and soft drop shadows.
- Fluid, soft transitions when clicking through menu categories or opening the language selection modal.
